# Интеграция Instagram

Выбран неофициальный instagrapi adapter и резервный JSON/ZIP импорт. В V1 нет OAuth-подключения, выдающего полные списки личного аккаунта. Безопасность доступа обеспечивается ограничениями приложения, а отсутствие блокировок не гарантируется.

Код: `backend/app/integrations/instagram.py`, `jobs/tasks.py`, `jobs/guard.py`, `modules/data.py`. Credentials передаются только HTTPS API → зашифрованный auth vault → auth worker, срок 10 минут. Job содержит ссылку на контекст, не пароль. Сохранённая сессия использует отдельный версионированный worker key. При sync сначала проверяется собственный ID; login не вызывается.

Реальные подключения намеренно не выполнялись: пользователь отложил этот этап. Для проверки подключить принадлежащий пользователю аккаунт один раз, подтвердить поддерживаемую 2FA, проверить успешный полный снимок, перезапуск worker и следующий сбор без нового login. При challenge завершить проверку через официальный Instagram; не организовывать повторные попытки. Затем проверить disconnect во время задания и отсутствие публикации старого результата. Результат записать в STATUS с датой и кодами состояний, без credentials и личных списков.

Технические проверки на поддельном клиенте покрывают budget, cursor, 429 без скрытого retry и несовпадение ID. Они не заменяют проверку актуального поведения Instagram.
